KEY BENEFITS:

✓ Clean separation of concerns (decision, routing, execution)
✓ Easy to extend (add new pipeline = add new branch)
✓ Debuggable (each pipeline independent)
✓ Matches human reasoning (is house? is complete? what action?)
✓ Testable (validate logic without dependencies)
✓ 8b model optimized (simplified discovery prompt)
